# 📰 NewsHub

A modern and responsive news application built with React that lets users browse the latest headlines by category, search articles, switch between light and dark themes, and save their favorite articles with bookmarks.

---

## ✨ Features

- 📰 Latest news using NewsAPI
- 📂 Browse news by category
- 🔍 Search articles instantly
- ❤️ Bookmark favorite articles
- 🌙 Light/Dark mode with persistence
- 💾 Bookmarks saved using Local Storage
- 📱 Fully responsive design
- ⏳ Skeleton loading screens
- ⚠️ Error handling with retry functionality
- 🔔 Toast notifications
- 🚀 Client-side routing using React Router

---

## 🛠️ Tech Stack

- React
- Vite
- React Router DOM
- Tailwind CSS
- Context API
- React Hot Toast
- React Icons
- NewsAPI

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/newshub.git
```

### Install dependencies

```bash
npm install
```

### Create an environment file

Create a `.env` file in the project root.

```env
VITE_NEWS_API_KEY=YOUR_API_KEY
```

### Start the development server

```bash
npm run dev
```
